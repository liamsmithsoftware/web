# آرشیو هوشمند مطالب وب‌سایت‌ها (Website Content Collector)

سامانه تحت وب (بومی، سبک و کاملاً راست‌به‌چپ) برای **جمع‌آوری خودکار، زمان‌بندی‌شده و بدون تکرار** مطالب و اخبار وب‌سایت‌ها، بخش‌های خبری و فیدهای RSS/Atom، ذخیره‌سازی ساختاریافته در دیتابیس محلی **SQLite** و دریافت خروجی استاندارد **Excel (`.xlsx`)** و **SQLite (`.sqlite`)**.

---

## ویژگی‌های کلیدی

- **بدون نیاز به API Key یا تنظیمات پیچیده از روز اول**: بلافاصله پس از اجرا با موتور ترکیبی **هوشمند (`Auto`: کشف خودکار RSS/Atom/JSON-Feed + استخراج مستقیم HTML)** مطالب وب‌سایت‌های عمومی را دریافت می‌کند.
- **پشتیبانی از انواع آدرس‌های وب‌سایت**:
  - آدرس کامل سایت (`https://www.zoomit.ir`) یا نام دامنه ساده (`zoomit.ir`)
  - بخش یا سرویس خاص از یک سایت خبری (`https://www.isna.ir/service/economy`) — هر بخش به صورت مستقل قابل زمان‌بندی است
  - لینک مستقیم خوراک خبری (`https://example.com/rss.xml` یا `https://example.com/feed`)
- **تکمیل خودکار متن کامل مقالات**: در صورت کوتاه بودن خلاصه موجود در فید یا صفحه اول سایت، برنامه به صورت هوشمند وارد صفحه هر خبر جدید شده و متن کامل مقاله، تاریخ دقیق انتشار و تصویر اصلی را استخراج می‌کند (قابل تنظیم در بخش تنظیمات).
- **قانون دقیق «اولین اجرا ۱۰ مطلب آخر + اجراهای بعدی فقط مطالب جدید»**:
  - در اولین اتصال به هر وب‌سایت، **صرفاً ۱۰ مطلب آخر** ذخیره می‌شود و تمام آیتم‌های موجود در صفحه در جدول کنترل تکرار (`seen_items`) ثبت می‌شوند تا در اجراهای بعدی مطالب قدیمی‌تر دوباره دریافت نشوند.
  - در بررسی‌های بعدی، **فقط و فقط مطالب تازه منتشرشده** واکشی و ذخیره می‌شوند.
  - قیود یکتایی دیتابیس (`UNIQUE(site_id, post_guid)` و `UNIQUE(site_id, post_url)`) به صورت اتمیک مانع ثبت هرگونه رکورد تکراری می‌شوند.
- **زمان‌بندی منعطف برای هر وب‌سایت**: تنظیم بازه بررسی به صورت **ساعتی** (مثلاً هر ۲ یا ۶ ساعت) یا **روزانه** (مثلاً هر ۱ روز)، همراه با امکان توقف موقت، دریافت فوری تکی یا همگام‌سازی یکجای همه وب‌سایت‌ها.
- **ذخیره‌سازی تفکیک‌شده تاریخ و زمان (شمسی و میلادی)**:
  - عنوان مطلب (`title`) و متن کامل تمیزشده (`content`)
  - تاریخ انتشار **شمسی / جلالی** (`1405/08/19`)
  - تاریخ انتشار **میلادی** (`2026-11-10`)
  - ساعت دقیق انتشار (`14:30:00`) بر اساس منطقه زمانی قابل تنظیم (پیش‌فرض `Asia/Tehran`)
  - آدرس مستقیم مطلب، نوع رسانه پیوست و آمار بازدید (در صورت وجود در سایت)
- **پشتیبانی از تاریخ‌های فارسی در صفحات وب**: تشخیص خودکار فرمت‌های ISO-8601، RFC-2822، تاریخ عددی شمسی (`۱۴۰۵/۰۸/۱۹ - ۱۴:۳۰`) و ماه‌های حروفی فارسی (`۱۹ آبان ۱۴۰۵ ساعت ۱۴:۳۰`).
- **خروجی استاندارد و تمیز**:
  - **خروجی Excel (`.xlsx`)**: دو شیت راست‌به‌چپ («مطالب وب‌سایت‌ها» و «لیست وب‌سایت‌ها») با سربرگ ثابت، فیلتر خودکار، لینک‌های قابل کلیک و ایمن‌سازی فرمول‌ها (امکان خروجی کل آرشیو یا صرفاً نتایج فیلترشده).
  - **خروجی دیتابیس SQLite (`.sqlite`)**: کپی اتمیک و ایمن (با پاک‌سازی خودکار رمزهای پروکسی و کوکی‌ها) به همراه View آماده گزارش‌گیری `vw_posts_export`.
- **پشتیبان‌گیری و بازیابی تنظیمات (JSON)**: خروجی کم‌حجم از لیست وب‌سایت‌ها، زمان‌بندی‌ها، عنوان‌های سفارشی و تنظیمات جهت انتقال آسان به سیستم دیگر (حالت‌های «ادغام» و «جایگزینی کامل»).
- **مدیریت و پاک‌سازی داده‌ها**: انتخاب چندتایی مطالب در جدول آرشیو، پیش‌نمایش و حذف گروهی بر اساس فیلتر (وب‌سایت، بازه تاریخ، نوع محتوا، کلیدواژه) با کنترل دقیق بازنشانی نشانگر سایت، تخلیه آرشیو با حفظ لیست سایت‌ها و بازگشت کامل به حالت اولیه.
- **تنظیمات پیشرفته شبکه و پروکسی**: پشتیبانی از پروکسی `SOCKS5` و `HTTP`، تنظیم `User-Agent` و `Cookie` سفارشی، کنترل بررسی گواهی SSL و ابزار **تست اتصال و بررسی ساختار سایت** پیش از افزودن.
- **همزیستی کامل با نسخه تلگرام**: در صورتی که برنامه آرشیو کانال‌های تلگرام روی پورت `8000` در حال اجرا باشد، این برنامه به طور خودکار پورت آزاد بعدی (`8001`) را انتخاب کرده و بدون هیچ تداخلی کنار آن اجرا می‌شود.

## پیش‌نیازها

- **Python 3.10** یا بالاتر (پیشنهادی: Python 3.11 یا 3.12)
  > در ویندوز هنگام نصب پایتون حتماً تیک گزینه **`Add Python to PATH`** را فعال کنید. نیازی به نصب ابزارهای C++ Build Tools نیست؛ تمام وابستگی‌ها دارای پکیج باینری آماده (Wheel) هستند.

## راهنمای نصب و اجرا (گام‌به‌گام)

### روش ۱: اجرای سریع در ویندوز (پیشنهادی — با دابل‌کلیک)

1. پوشه پروژه را در مسیر دلخواه قرار دهید.
2. روی فایل **`start_windows.bat`** دابل‌کلیک کنید.
3. اسکریپت هوشمند `launcher.py` به صورت خودکار:
   - نسخه پایتون سیستم را شناسایی می‌کند (`py -3` یا `python`)
   - محیط مجازی `.venv` را می‌سازد
   - وابستگی‌ها را نصب می‌کند (فقط در اولین اجرا؛ در اجراهای بعدی مستقیم و فوری وارد برنامه می‌شود)
   - سرور وب را راه‌اندازی کرده و مرورگر شما را روی آدرس پنل باز می‌کند:
     **`http://localhost:8000`**
4. برای توقف کامل سرور در ویندوز می‌توانید پنجره برنامه را ببندید (`Ctrl+C`) یا روی فایل **`stop_windows.bat`** دابل‌کلیک کنید.

### روش ۲: اجرای سریع در لینوکس و macOS

```bash
chmod +x start_linux_mac.sh
./start_linux_mac.sh
```

سپس مرورگر را باز کرده و وارد آدرس **`http://localhost:8000`** شوید.

### روش ۳: اجرای دستی با دستورات پایتون

```bash
# ساده‌ترین حالت (ساخت خودکار venv + نصب پکیج‌ها + اجرا)
python launcher.py

# یا اجرای مستقیم پس از فعال‌سازی محیط مجازی:
python -m venv .venv
source .venv/bin/activate        # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
python run.py --port 8000
```

### روش ۴: اجرا با Docker (مناسب سرور ۲۴/۷)

```bash
docker compose up -d --build
```

تمام داده‌ها و خروجی‌ها در پوشه `./data` روی سیستم میزبان ذخیره و پایدار می‌مانند.

در فرم «افزودن وب‌سایت جدید» هر یک از حالت‌های زیر به صورت خودکار نرمال‌سازی می‌شود:

| نوع ورودی | نمونه | نتیجه نرمال‌سازی |
|---|---|---|
| آدرس کامل وب‌سایت | `https://www.zoomit.ir/` | `https://www.zoomit.ir/` (کلید: `zoomit.ir`) |
| نام دامنه بدون پروتکل | `digikala.com/mag` | `https://digikala.com/mag` (کلید: `digikala.com/mag`) |
| بخش یا سرویس خبری خاص | `https://www.isna.ir/service/economy` | پایش مستقل همان بخش اقتصادی |
| لینک مستقیم RSS / Atom | `https://example.com/rss.xml` | خواندن مستقیم خوراک خبری |

## حالت‌های موتور جمع‌آوری وب (`collector_mode`)

در زبانه **«تنظیمات و پروکسی»** می‌توانید روش خواندن وب‌سایت‌ها را انتخاب کنید:

1. **هوشمند (`Auto` - پیش‌فرض و پیشنهادی)**:
   ابتدا بررسی می‌کند آیا صفحه مورد نظر دارای خوراک استاندارد (RSS 2.0 / Atom / JSON Feed) هست یا خیر (با رعایت تفکیک بخش‌های داخلی سایت تا فید کلی سایت جایگزین بخش تخصصی نشود). اگر فید معتبر در دسترس نبود، به صورت خودکار صفحه وب را با موتور استخراج HTML پیمایش می‌کند.
2. **فقط خوراک خبری (`RSS / Atom / JSON Feed`)**:
   صرفاً از طریق فید سایت یا مسیرهای رایج (`/feed`، `/rss`، `/rss.xml`، `/atom.xml`) اقدام به دریافت مطالب می‌کند.
3. **فقط استخراج مستقیم صفحه وب (`HTML Scraper`)**:
   بدون توجه به فید، مستقیماً ساختار DOM صفحه، داده‌های ساختاریافته `JSON-LD` و کارت‌های خبری (`<article>` و تیترها) را استخراج می‌کند؛ مناسب سایت‌هایی که فید RSS ندارند یا فید آن‌ها ناقص و قدیمی است.

## ساختار دیتابیس SQLite (`data/web_collector.sqlite`)

- جدول **`sites`**: مشخصات وب‌سایت‌ها، کلید یکتا، عنوان، بازه زمان‌بندی، نشانگر آخرین اجرا و وضعیت فعال/متوقف.
- جدول **`posts`**: آرشیو مطالب شامل عنوان (`title`)، متن کامل (`content`)، تاریخ شمسی (`published_jalali_date`)، تاریخ میلادی (`published_date`)، ساعت انتشار (`published_time`)، لینک یکتا (`post_url`)، نوع رسانه و آمار بازدید.
- جدول **`seen_items`**: حافظه شناسه‌های مشاهده‌شده جهت جلوگیری صددرصدی از دریافت مجدد مطالب قدیمی‌ترِ صفحه اول یا مطالب حذف‌شده توسط کاربر.
- جدول **`fetch_logs`**: گزارش کامل هر نوبت واکشی (زمان اجرا، نوع اجرا، تعداد مطالب جدید اضافه‌شده و خطاها).
- جدول **`settings`**: تنظیمات کلی برنامه، حالت موتور وب، منطقه زمانی و تنظیمات پروکسی/هدرها.
- نمای **`vw_posts_export`**: View آماده با ستون‌های فارسی‌شده برای کوئری‌گیری آسان در نرم‌افزارهایی نظیر DB Browser for SQLite یا Power BI.

## ساختار پوشه‌ها و فایل‌های پروژه

```text
.
├── app/
│   ├── api/routes.py             # مسیرهای REST API (وب‌سایت‌ها، آرشیو، خروجی، بکاپ، پاک‌سازی)
│   ├── collectors/
│   │   ├── base.py               # مدل‌های داده و خطاهای جمع‌آوری
│   │   ├── feed_parser.py        # پارسر RSS 2.0 / RDF / Atom / JSON Feed و کشف خودکار فید
│   │   ├── html_scraper.py       # استخراجگر هوشمند لیست اخبار، JSON-LD و متن کامل مقالات
│   │   ├── web_collector.py      # هماهنگ‌کننده شبکه (HTTPX، پروکسی، هدرها و تست اتصال سایت)
│   │   └── manager.py            # مدیریت همگام‌سازی دو مرحله‌ای و جلوگیری از تکرار
│   ├── services/
│   │   ├── exporter.py           # تولید فایل Excel راست‌به‌چپ (.xlsx) و اسنپ‌شات SQLite
│   │   └── scheduler.py          # زمان‌بند پس‌زمینه (APScheduler)
│   ├── static/                   # استایل‌های RTL بومی و منطق جاوااسکریپت آفلاین
│   ├── templates/index.html      # رابط کاربری تک‌صفحه‌ای ۶ زبانه‌ای فارسی
│   ├── utils/
│   │   ├── jalali.py             # تبدیل و تشخیص تاریخ‌های شمسی، میلادی و رشته‌های فارسی
│   │   └── site_parser.py        # نرمال‌سازی آدرس سایت‌ها و حذف پارامترهای تبلیغاتی (utm_*)
│   ├── config.py                 # تنظیمات پایه و متغیرهای محیطی
│   ├── database.py               # لایه دیتابیس SQLite (WAL)، پشتیبان‌گیری JSON و پاک‌سازی
│   ├── main.py                   # نقطه ورود برنامه FastAPI
│   └── schemas.py                # مدل‌های اعتبارسنجی Pydantic
├── tests/                        # تست‌های خودکار واحد و یکپارچه (Pytest)
├── launcher.py                   # راه‌انداز هوشمند بدون نیاز به پیش‌نیاز دستی
├── run.py                        # اسکریپت اجرای سرور با تشخیص خودکار پورت آزاد
├── start_windows.bat             # اجرای تک‌کلیکی در ویندوز (ASCII خالص + CRLF)
├── stop_windows.bat              # توقف ایمن برنامه در ویندوز
├── start_linux_mac.sh            # اجرای تک‌کلیکی در لینوکس و مک
├── Dockerfile & docker-compose.yml
└── requirements.txt
```
